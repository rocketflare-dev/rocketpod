## What changed

Agents can ask typed questions through `ctx.decide` (D37) — answered with probabilities by TypeSafe's Jev, a new `decisions` AI provider scope, or by the chat model — recorded per run, scored by evals and shown on the run page.

- `ctx.decide(key, { state, questions })`, `ctx.decide.sift`, `ctx.decide.pick` on `AgentContext` and the plugin `AgentCtx`; recorded once per `(run, key)` in `agent_run_decisions` and replayed on a retry.
- New AI scope `decisions` and provider `typesafe` (Settings → AI, with a Test button); platform secret `TYPESAFE_API_KEY`; without either, the chat model answers on prompt key `agent-decide`, recorded `llm_self_report`.
- `resolveDecisions` in `services/ai/resolve.ts`; readiness gains `decisions` and the source `fallback`.
- New run event type `decision`, projected to AG-UI as `kit.agent.decision`; `GET /api/agents/runs/:id` returns `decisions[]`; the run timeline shows a *Decided* row.
- `ctx.prompt(vars, promptKey?)` may resolve another registry prompt.
- New example agent `triage-research` (screen → triage → answer, "not covered", or escalate to `research-topic`) with an eval suite.
- Evals: `expected.decisions` on `EvalCase`, `DecisionJudge`, `decisionScore` (accuracy + Brier).
- Retrieval: the lexical half of `searchChunks` matches ANY query word (ranked by `ts_rank_cd`) instead of ALL of them, so a question typed as a sentence finds passages by its key terms.
- Fix: the Run modal's schema-generated form (any agent with no hand-written form) remounted its fields on every keystroke, losing focus; `RunAgentModal` now builds the form once.
- Why: `docs/CONCEPTS.md` §9, "Decisions (D37)".
- `scripts/lib/kit-manifest.mjs` → the kit contract's optional `launchProvides.oidc.callbackPath` (default `/auth/oidc/callback`) and `signedOutPath` (default `/login?signedOut=1`) must each be a path on the app's origin: one leading `/`, no scheme, host, whitespace or `#` (launch-kit 0.1.4).
