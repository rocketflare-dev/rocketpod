## What changed

Rocketpod catches up with Rocketflare 0.40.0: a durable agent runtime, a structured knowledge base with typed facts, two security rounds, a remote MCP server at `/mcp`, and upgrade tooling that resumes after rejects.

- Per-release detail (what was ported, translated, skipped) is in `docs/FORK.md`; the line-by-line porting note this summary replaces is `git show 4257cd0:docs/upgrades/unreleased.md`. Rocketflare 0.35.0 (the security-audit skill) is not ported yet.
- **Breaking — AG-UI:** a cancelled run projects as `RUN_FINISHED { outcome: { type: 'cancelled' } }`, not `RUN_ERROR` `agent_run_cancelled`.
- **Breaking — `ctx.once` keys:** stored as `label#<hash of inputs>`; the same key twice in one attempt throws `EffectKeyConflictError` (`agent_effect_key_conflict`, never retried).
- Durable runs ([CONCEPTS §9](../CONCEPTS.md)): the turn journal (`agent_run_turns`, `ctx.journal`, `runToolLoop({ journal })`, `Tool.sideEffects` / `Tool.durable`), cancel reaching the call in flight (`ctx.signal`), the `*/10` lost-run sweeper and ask reminders, `meta.version` / `onVersionChange`, ask deadlines and assignees, child runs (`ctx.spawn`), `GET /api/agents/runs/:id/timeline` and `/api/agents/stats`, the agents pages and run inspector, CLI `agents inspect`.
- A missing engine run is the typed `RunInstanceNotFoundError` (`src/platform/types.ts`); `agent_runs.worker_version_id` comes from `APP_VERSION_ID`.
- Knowledge ([CONCEPTS §9](../CONCEPTS.md)): chunks cut at headings and table rows with `embedding_model` per chunk, `document.reembed` on a model change, content-hash dedupe, document retry, facets, an optional HTTP reranker (the tenant `rerank` scope), the Search page.
- Knowledge facts behind the `knowledge-facts` flag: entities, facts, the extraction job (paused by `KNOWLEDGE_TENANT_DAILY_COST_USD`), review, the decision-model judge, `lookup_facts`, the Facts view, entity cards in chat and on the run timeline.
- Security round 3: suspended tenants run no agents (`hooks.onTenantStatusChanged`); invitation issuers re-checked at accept; the ownership ceiling on promotion and a daily creation counter; API keys kept to their organisation; AI config saves lock their row; `ctx.decide`'s fallback metered; the sign-in mail window per canonical mailbox; upload-path body caps; Microsoft domain proof.
- Security round 4: facts follow document visibility on the producing side; a member's `prefer` refused with 403 `fact_conflict_needs_admin`; blocking a person revokes every invitation they issued; the jobs consumer acks unrun a suspended tenant's jobs (`tenant.purge` and `activity.record` excepted); the chunker scans in linear time.
- `ToolCtx.requesterUrls`; `GET /auth/session` `canCreateTenant` hides "Create organisation".
- `/mcp`: the agents' tools offered to MCP clients behind an outside OAuth server (`MCP_AUTHORIZATION_SERVER`, off until set; [CONCEPTS §19](../CONCEPTS.md)); new dependency `@modelcontextprotocol/sdk`.
- Tooling: `pnpm kit:upgrade --continue` and `pnpm plugin upgrade <id> --continue`; `plugin upgrade` formats what it wrote; the CLI resolves paths from where it was run and warns when env keys override a saved login; `pnpm test` refuses Node < 26.
- Tracing: a job's span is `invoke_workflow <type>`, a `run started` span, `gen_ai.conversation.id`, semconv 1.45.0. Lint: a Biome warning now fails the gate.

## How to apply

1. Run `pnpm install` (the release adds `@modelcontextprotocol/sdk`).
2. Port the schema in `apps/web/src/db/schema/` (the frontmatter's migration list), run `pnpm db:generate`, then `pnpm db:migrate`; never copy the kit's migration files.
3. In the migration that changes `chunks`, put `CREATE EXTENSION IF NOT EXISTS pg_trgm` first, backfill `chunks.embedding_model` from `documents`, and drop and re-add `search_vector` with its GIN index after the new columns; on a managed database, allow the migration role to create `pg_trgm`.
4. Plan the `chunks` migration: it rewrites the table under an exclusive lock, so above about a million chunks run it in a maintenance window (`docs/DEPLOY.md`).
5. Add the new optional keys to `.env`, Helm `config` and, for `APP_VERSION_ID`, compose: `APP_VERSION_ID` (Helm defaults it to the image tag), `AGENT_TRANSCRIPT_RETENTION_DAYS` (30), `KNOWLEDGE_TENANT_DAILY_COST_USD`, `RERANK_CANDIDATES` (20), `RERANK_MIN_SCORE`, `MCP_AUTHORIZATION_SERVER`.
6. Update every AG-UI client that keyed on `RUN_ERROR` `agent_run_cancelled` to read `RUN_FINISHED`'s `outcome.type === 'cancelled'`.
7. Give every `ctx.once` inside a loop that reused one label the varying values as `{ inputs }`, so each call's key differs.
8. Update your own callers of `setTenantSuspended` to its single input object with `platform`, and of `findEntitiesByName` / `entitiesMentionedIn` to pass an `AccessScope`.
9. Fix every Biome warning; `pnpm lint` now fails on them.
10. Check each kit-wide agent tool you added to `buildAgentTools` is safe to offer to an MCP client: `/mcp` offers every tool with a handler and no approval gate.
11. Regenerate `docs/plugin-api.md` with `node scripts/plugin-api-doc.mjs` if your copy publishes it.
12. For a change not covered by steps 1–11, follow the Rocketflare porting note named in that release's `docs/FORK.md` row, as translated in the row, or the detailed text in `git show 4257cd0:docs/upgrades/unreleased.md`.
