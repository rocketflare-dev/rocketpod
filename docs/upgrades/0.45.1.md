## What changed

Rocketpod catches up with Rocketflare 0.45.0: run timelines show model calls, knowledge gains a Promote picker, contextual prefixes and CLI `docs`/`facts`, `plugin check` parses source, a guard and a UI lint steer agents, and Home and sign-in are redesigned.

- What each Rocketflare change became here is in `docs/FORK.md` (row 0.45.0). The detailed per-change text is in `git show 280f32e:docs/upgrades/unreleased.md`. Rocketpod 0.45.0 carried only Rocketpod's own changes, so a plugin whose `minKit` is 0.45.0 needs this release.
- Agents: every `ctx.chat.client` call writes a `tool.start`/`tool.end` pair marked `kind: 'model'` (`services/agents/recording.ts`, `ToolLoopJournal.onEvent`), shown on the run page and skipped by AG-UI, the evals export and transcripts; an agent no longer brackets its own model calls. Answering an ask marks its notifications read, and `GET /api/agents/interrupts?mine=true` feeds the badge. `docs/CONCEPTS.md` §9.
- Knowledge: a Promote picker (`GET /api/knowledge/entities/:id/promote-candidates`), `EntityTypeRegistration.mentions` for search facts, and the review badge on its own query key `['knowledge-review-count']`.
- Contextual prefixes, behind the `knowledge-context` flag (off): the `document.contextualize` job, the `knowledge-context` prompt, usage feature `knowledge.context`, `chunks.context`/`context_model`, the stored `search_vector` reading the context first, and `POST /api/ai/documents/contextualize` with the Search page's "Add context" notice.
- CLI: `docs list|search|ingest|retry` and `facts review|confirm|reject|prefer`.
- Tooling: `pnpm plugin check` parses the TypeScript AST and fails on an unresolvable or `cloudflare:*` import; `pnpm design:lint`; the kit guard (`scripts/kit-guard.mjs`, Claude Code hooks in `.claude/settings.json`, `.rocketflare.json` `guard`/`localEdits`); the brand, contrast and design-docs tooling, with a hex mode for a hex palette. `docs/CONCEPTS.md` §13 and §16.
- UI: Home is a dashboard laid out from `pages/home-sections.ts` over `GET /api/home/summary` (`@rocketpod/shared/home`), with `RunsChart`/`TrendLine`/`AvatarStack`; sign-in is a split screen (`LoginArt`, `ui/lib/login-panel.ts`); `Provenance` is the one source treatment, exported to plugins; runs carry `requestedBy` and accept `?until=`; status sentences, Run again, search highlighting without ranks, dates without the current year and a short `timeAgo`; the rail reads `--rail-*` tokens.
- Not applied: Rocketflare's ember look. Rocketpod keeps its palette and fonts; `pnpm design:docs --adopt-default-look` adopts it on request. `docs/CONCEPTS.md` §7.
- Also in this release, Rocketpod's own: a release workflow for AWS ECS on infrastructure managed elsewhere (`.github/workflows/deploy-aws.yml`, one `AWS_DEPLOY_CONFIG` variable). `docs/DEPLOY.md` § AWS ECS.
